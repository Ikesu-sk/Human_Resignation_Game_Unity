# Human_Resignation_Game_Unityfeature/2025-08-06
2025年8月6日時点でのunityをベースとしたヒト辞任ゲームの進捗

## このデータの進捗状況
[📺 [【Unity】１時間でノベルゲームを作ろう！！]](https://www.youtube.com/watch?v=MCnYgVw3Xq8&t=3285s)

こちらの動画を参考にノベルゲーム風のUIとシステムを作成。中身は動画内のものとほぼ同一。

これからゲーム部分の作成、yolo機能の搭載、オリジナルキャラクターの作成などを行っていく予定。

## インストール方法
```bash
git clone https://github.com/Ikesu-sk/Human_Resignation_Game_Unity.git
```
### 使い方（How to Use）
インストールしたディレクトリ`Human_Resignation_Game_Unity`をunity hubで開く。
その後、Assets > Scenes > Main を開けば参考動画と同じような画面が出てくる。
